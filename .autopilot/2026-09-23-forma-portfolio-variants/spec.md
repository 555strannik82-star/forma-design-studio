# Спецификация: FORMA — 3 варианта портфолио-сайта

## Задача

Студия ремонта и дизайна интерьеров FORMA хочет выбрать визуальное направление для своего портфолио-сайта. Нужно увидеть три принципиально разных подхода к одному и тому же контенту, чтобы выбрать лучший.

## Решение

Три полноценных варианта сайта в одном проекте. Каждый — отдельная HTML-страница со всеми секциями, своей типографикой, анимациями и ритмом. Плавающая панель в углу экрана позволяет мгновенно переключиться между вариантами. Все три варианта работают на тёмном графитовом фоне с тёплой палитрой (Ivory/Sand/Taupe/Mocha/Gold), но каждый использует её по-своему.

### Три направления

**Вариант A — «Редакция»** (вдохновлён реф. 2, 5)
Крупная серифная типографика как главный визуальный элемент. Playfair Display в огромном размере, Cormorant Garamond italic для акцентов. Вертикальный ритм: чередование полноэкранных текстовых блоков и сеток фотографий. Scroll-анимации: плавное появление (fade + translate-up). Классическая редакционная эстетика.

**Вариант B — «Кино»** (вдохновлён реф. 1, 3)
Полноэкранные фото/видео как основа. Минимум текста поверх изображений. Горизонтальные галереи внутри вертикального скролла. Параллакс и масштабирование на скролле. Кинематографичное, иммерсивное ощущение. Выноски с пояснениями поверх фото.

**Вариант C — «Конструктор»** (вдохновлён реф. 4, 6)
Жирный сжатый sans-serif для заголовков. Асимметричные сетки. Карточные раскладки проектов. Анимации раскрытия/разворачивания (концепт коробки из реф. 6). Геометрические акценты, линии-разделители. Современная архитектурная эстетика.

## Решения по реализации

### §0. Дизайн-система и анализ референсов

Анализ 6 референсов выполнен ранее (файл `design-system.md` в корне проекта). Общие черты: тёмный фон, тёплая палитра натуральных материалов, крупная контрастная типографика, полноэкранные фото, обилие воздуха. Дизайн-система включает:

- **Палитра** — см. §6
- **Типографика** — «двуголосие»: display serif/sans + акцентный italic + нейтральный body
- **Сетка** — 12-колоночная на десктопе (1200px max-width), 4-колоночная на мобильных; gap 24–32px; секции чередуют full-bleed и contained layouts
- **Ритм** — vertical rhythm 8px; секции разделены крупными паузами (120–200px); чередование: текст-доминантная → фото-доминантная → смешанная
- **Пространство** — минимум 40% белого пространства на экран; padding секций не менее 80px по вертикали

Записано в `styles/tokens.css`: CSS-переменные покрывают не только цвета и шрифты, но и отступы, размеры сетки и breakpoints.

### §1. Стек и структура файлов

Vanilla HTML/CSS/JS. Без фреймворков, сборщиков, npm. Шрифты — Google Fonts. Анимации — CSS + Intersection Observer API. Hero-шейдеры — Three.js (r128, CDN). Каждый вариант — отдельный HTML-файл: `variant-a.html`, `variant-b.html`, `variant-c.html`. Общий CSS с токенами — `styles/tokens.css`. Компонент переключателя — `styles/switcher.css` + `scripts/switcher.js`.

Почему так: уже существующий index.html построен на vanilla-стеке, менять нет причин. Отдельные файлы, а не SPA — мгновенный переход через prefetch, нет JS-зависимости для рендера.

### §2. Секции (все варианты)

Каждый вариант содержит одни и те же смысловые секции, но в разном визуальном исполнении:

1. **Hero** — заголовок студии + CTA + анимированный фон
2. **О студии** — кратко о FORMA, философия подхода
3. **Портфолио** — фото проектов (3–6 штук, placeholder-изображения)
4. **Услуги** — что делает студия (дизайн, ремонт, авторский надзор)
5. **Процесс** — этапы работы (визуально, не текстом)
6. **Контакт** — CTA + форма/контакты

Почему так: стандартный набор для портфолио студии дизайна; меньше — не расскажешь о себе, больше — перегрузишь.

### §3. Переключатель вариантов

Плавающая панель: фиксированный элемент в правом нижнем углу. Три кнопки (A / B / C), текущий вариант выделен золотым. При клике — переход на соответствующую страницу с сохранением scroll-позиции (через URL-якорь текущей секции). Панель полупрозрачная, не мешает контенту, скрывается при скролле вниз и появляется при скролле вверх.

Почему так: минимально инвазивный UI, всегда доступен, не отвлекает от просмотра.

### §4. Шрифтовые пары

| Вариант | Заголовки | Акцент | Тело |
|---------|-----------|--------|------|
| A «Редакция» | Playfair Display 700 | Cormorant Garamond 300 italic | Inter 400 |
| B «Кино» | Inter 800 uppercase | Cormorant Garamond 300 italic | Inter 300 |
| C «Конструктор» | Oswald 700 condensed | Playfair Display 400 italic | Inter 400 |

Почему так: три принципиально разных характера — классическая серифная роскошь, минималистичный кинематограф, архитектурный конструктивизм.

### §5. Анимации

| Вариант | Hero-фон | Scroll-reveal | Особые эффекты |
|---------|----------|---------------|----------------|
| A | Тёплые кольца (Three.js, из существующего index.html) | fade + slide-up, stagger | Фото-сетка: масштаб при наведении |
| B | Мерцающие частицы (Three.js) | parallax + scale | Горизонтальная прокрутка галереи внутри секции |
| C | Геометрические линии (Canvas 2D) | unfold/clip-path reveal | Карточки раскрываются при скролле |

Все анимации уважают `prefers-reduced-motion`: при включённой настройке — статичные переходы.

### §6. Палитра

Общая база из реф. 3:
- `--black: #0A0A08`
- `--charcoal: #1A1714`
- `--surface: #252220`
- `--border: #3A3530`
- `--ivory: #F0EDE6`
- `--sand: #D4C9B0`
- `--taupe: #8A7A68`
- `--mocha: #5C4A38`
- `--gold: #C8A45A`
- `--gold-light: #E6CC92`

Каждый вариант использует один и тот же набор, но с разным акцентным балансом:
- A: акцент gold, фон charcoal, текст ivory
- B: акцент gold-light, фон чистый чёрный, текст sand
- C: акцент оранжевый (#D4864A), фон charcoal, текст ivory

### §7. Контент

Весь текст — placeholder на русском языке, стилистически подходящий для студии дизайна интерьеров. Фото — placeholder-блоки с градиентами (реальные фото студия предоставит позже). Цены, адреса, телефоны — видимые заглушки `[НАЗВАНИЕ СТУДИИ]`, `[АДРЕС]`, `[ТЕЛЕФОН]`.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `tokens` | CSS-переменные, шрифты, общие стили | `tokens.css` — подключается во все варианты | расчёт значений |
| `switcher` | UI переключателя, состояние текущего варианта | `initSwitcher(currentVariant)` — вызывается на каждой странице | логику показа/скрытия при скролле, prefetch |
| `animations` | Intersection Observer, scroll-trigger | `initScrollAnimations()`, CSS-классы `.reveal`, `.parallax` | threshold, timing, stagger-логику |
| `hero-shader` | WebGL-контекст, шейдерный код для каждого варианта | `initHeroShader(variant)` — variant = 'a'|'b'|'c' | шейдерный код, RAF-цикл |
| `variant-a/b/c` | HTML-структура, variant-specific CSS | HTML-файл, подключает общие модули | внутреннюю разметку секций |

Швы для тестов: один — страница загружается, переключатель работает, все секции видимы.
