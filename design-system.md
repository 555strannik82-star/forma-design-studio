### Правило использования

- Фон по умолчанию — **тёмный** (рефы 1, 2, 3, 5 подтверждают)

- Белый текст (ivory) — только для заголовков; тело — sand/taupe
- Светлая тема сохраняет тот же тональный порядок, но инвертированный

## 2. Типографика

### Приём, который повторяется во всех 6 референсах

**Двуголосие**: жирный сухой шрифт (констатация) + курсивный/рукописный (эмоция).

Примеры из референсов:
- `LUXURY APARTMENT` (serif caps) + `Modern. Elegant. Timeless.` (spaced gold)
- `WE DON'T DESIGN HOUSES.` (bold caps) + `WE DESIGN STATUS.` (gold italic)
- `PENTHOUSE` (serif caps) + `Design` (script)
- `A KITCHEN THAT KNOWS YOUR` (bold condensed) + `Routine` (orange script)
- `Modern` (script gold) + `LUXURY INTERIORS` (serif caps + spaced)
- `UNFOLD YOUR DREAM KITCHEN` (bold condensed) + подстрочник italic

### Шрифтовая карта

| Роль | Шрифт | Начертание | Использование |
|------|-------|-----------|---------------|
| Display (hero) | Playfair Display | 700, 700 italic | Основной заголовок, крупный текст |
| Accent (эмоция) | Cormorant Garamond | 300 italic | Акцентное слово в заголовке, цитаты |
| Body | Inter | 300, 400, 500 | Описания, навигация, лейблы |
| Label | Inter | 500 | CAPS, letter-spacing: 0.18em, мета |

### Шкала размеров

```
--text-hero:   clamp(56px, 8vw, 110px)    заголовок первого экрана
--text-h2:     clamp(36px, 5vw, 64px)     заголовки секций
--text-h3:     clamp(22px, 3vw, 32px)     подзаголовки
--text-body:   15px                        основной текст
--text-label:  11px                        лейблы, мета
--text-small:  12px                        сноски, подписи
```

### Правила набора

- Заголовок hero: `text-transform: uppercase`, `letter-spacing: -0.02em` (Playfair)
- Акцентное слово: `font-style: italic`, цвет `--gold`, кегль на 10–20% меньше hero
- Лейблы секций: `text-transform: uppercase`, `letter-spacing: 0.15–0.2em`, цвет `--gold`
- Тело текста: `font-weight: 300`, `line-height: 1.7`, цвет `--sand`
- Ширина строки: не более 65 символов
- `text-wrap: balance` на всех заголовках

## 3. Сетка и лейаут

### Hero-секция (рефы 1, 4)

```
┌──────────────────────────────────────┐
│  [logo — мелкий, верхний левый]      │
│                                      │
│  ЗАГОЛОВОК                           │
│  Акцентное слово                     │
│  ──────────── (тонкая золотая линия) │
│  Подзаголовок мелким шрифтом         │
│                                      │
│  ┌─────────────────────────────────┐ │  ← полноэкранное фото
│  │     интерьер / рендер           │ │    (ref 1: анимируется)
│  │     с тёплым светом             │ │
│  └─────────────────────────────────┘ │
│                                      │
│  [иконка] [иконка] [иконка] [иконка] │  ← strip с услугами
└──────────────────────────────────────┘
```

- Фото интерьера — **на всю ширину**, текст поверх с gradient-overlay
- Overlay: `linear-gradient(to bottom, rgba(10,10,8,0.7) 0%, transparent 45%, rgba(10,10,8,0.8) 85%)`
- Навигация — sticky, полупрозрачная, blur

### Секции контента (реф 5)

```
┌──────────────────────────────────────┐
│  EYEBROW LABEL (gold, spaced caps)   │
│  Заголовок секции                    │
│  Подзаголовок (italic, gold)         │
│                                      │
│  ┌─────┐ ┌─────┐ ┌─────┐            │
│  │     │ │     │ │     │  ← карточки │
│  │ фото│ │ фото│ │ фото│    или     │
│  │     │ │     │ │     │    блоки    │
│  └─────┘ └─────┘ └─────┘            │
│  Caption   Caption   Caption         │
└──────────────────────────────────────┘
```

### Основная сетка

```
--grid-max:    1200px       максимальная ширина контента
--grid-gutter: 24px         боковые отступы (padding-inline)
--grid-gap:    16px         зазор между карточками в гриде
--section-pad: 96px         вертикальный padding секций (desktop)
--section-pad-mob: 64px     вертикальный padding секций (mobile)
```

### Сетка портфолио (реф 5 — блоки с информацией)

- Desktop: `grid-template-columns: repeat(3, 1fr)` — 3 колонки
- Первый элемент: `grid-column: span 2` — акцентный проект
- Каждая ячейка: `aspect-ratio: 4/3`, фото с overlay и подписью снизу
- Tablet: 2 колонки; mobile: 1 колонка

### Сетка услуг

- Desktop: 4 колонки, разделённые 1px линией (background grid trick)
- Tablet: 2 колонки; mobile: 1 колонка

## 5. Компоненты

### Кнопки

```css
/* Primary (CTA) */
.btn-gold {
  background: var(--gold);
  color: var(--black);
  padding: 14px 28px;
  font: 500 12px/1 'Inter', sans-serif;
  letter-spacing: 0.08em;
  text-transform: uppercase;
  border-radius: 2px;
}
.btn-gold:hover { background: var(--gold-light); }

/* Secondary */
.btn-outline {
  border: 1px solid var(--gold-line);
  color: var(--ivory);
  /* same dimensions */
}
.btn-outline:hover { border-color: var(--gold); color: var(--gold); }
```

### Карточки

- Фон: `--charcoal`
- Рамка: `1px solid var(--border)`
- `border-radius: 2–4px` (минимальный — острые углы = премиум)
- Hover: фон чуть светлее (`--surface`) + `border-left: 2px solid var(--gold)`
- Никаких теней — premium = плоскость и линии

### Разделители

- Между секциями: нет видимого разделителя, смена фона достаточна
- Внутри секций: `1px solid var(--border)` или `1px solid var(--gold-line)` для акцента
- Декоративный элемент: маленький ромб `◆` золотого цвета (рефы 1, 3, 5)

### Иконки

- Линейные, `stroke-width: 1.2`, цвет `--gold`
- Размер: 32–40px
- Стиль: архитектурный / чертёжный (тонкие линии, без заливки)

### Фото-карточки портфолио

```css
.portfolio-card {
  position: relative;
  aspect-ratio: 4/3;
  overflow: hidden;
  border-radius: 4px;
}
.portfolio-card img {
  transition: transform 0.45s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}
.portfolio-card:hover img { transform: scale(1.05); }
.portfolio-card .overlay {
  background: linear-gradient(to top,
    rgba(10,10,8,0.82) 0%,
    rgba(10,10,8,0.1) 55%,
    transparent 80%
  );
}
```

## 6. Анимации (для будущей реализации)

### Hero-фото (из рефа 1)

- При загрузке: `scale(1.08) → scale(1)` за 1.5s, ease-out
- При скролле: subtle parallax `translateY` со скоростью 0.3× скролла
- Overlay градиент слегка смещается при движении мыши (pointer-tracking)

### Заголовки секций

- `translateY(30px) + opacity(0) → translateY(0) + opacity(1)` при появлении в viewport
- Задержка между строками: 0.1s
- Не парковать в `opacity: 0` — начальное состояние видимое, анимация усиливает

### Карточки

- Stagger-появление: каждая следующая с задержкой +0.06s
- `translateY(20px) → translateY(0)`, без scale

### Правило

- `prefers-reduced-motion: reduce` → все анимации отключены
- Все элементы видимы без JS (no layout shift)

## 8. Визуальные принципы (вытекают из всех 6 рефов)

1. **Фото = фон.** Интерьер не в рамке — он IS фон. Текст живёт поверх.
2. **Золото — на кончике языка.** Не заливать золотом — один акцент на экран.
3. **Шрифт говорит двумя голосами.** Bold caps = факт. Italic = чувство.
4. **Тёмное пространство = воздух.** Чёрный фон — это не «пусто», это luxury-пауза.
5. **Ритм плотность/разрежение.** Hero (разреженный, дышит) → Info-блок (плотный) → Фото (дышит) → Данные (плотный).
6. **Острые углы.** Border-radius 2–4px максимум. Скругления = casual. Прямые линии = premium.
7. **Тёплый свет.** Все фото с golden-hour тональностью. Холодный свет запрещён.
